## How to read the git history honestly

Every commit in this repository is authored by the single account
`tufayelahmedsuhagcc-dotcom`, because the code, documentation and media were committed from one
machine during the event. That is a fact about the commit log, not a claim about who did the work:
the research, data verification, methodological review and filming listed above are real
contributions that did not happen to produce commits.

We deliberately did **not** manufacture commits from other accounts to make the contributor graph
look like a team. If you are judging team composition, use this table and the Space Apps team page
rather than the commit count.
